# Redes de computadoras

Internet por dentro, a nivel universitario: *sockets*, Ethernet, IP, enrutamiento con Dijkstra, Bellman-Ford y BGP, TCP y el control de congestión, QUIC, DNS, NAT y redes definidas por software, con simuladores de paquetes y prácticas con herramientas públicas.

**Ver en línea:** https://aaramirez.github.io/redes-de-computadoras/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
